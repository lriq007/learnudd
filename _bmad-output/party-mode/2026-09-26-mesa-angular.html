IV. La base

El "desde": standalone, signals, control de flujo moderno, ngModel. Con ejemplo, no con promesa.

🏗️
WINSTONStandalone components — sin NgModule, cada componente declara sus propios imports.
💻
AMELIASignals y computed() para el estado; @if / @for / @empty en el template. Es el default de Angular moderno, no una librería extra.
explore.component.html
@if (filtered().length > 0) {
  <ion-list>
    @for (note of filtered(); track note.id) {
      <ion-item>{{ note.title }}</ion-item>
    } @empty {
      <ion-item>No hay apuntes que coincidan.</ion-item>
    }
  </ion-list>
} @else {
  <ion-spinner></ion-spinner>
}
🏗️
WINSTONngModel sobre un signal no es el shorthand de siempre: [ngModel]="email()" (ngModelChange)="email.set($event)" — sigue siendo FormsModule, la señal solo vive por debajo.
